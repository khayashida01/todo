# TODO アプリ

素の HTML / CSS / JavaScript だけで作られたシンプルな TODO アプリです。ビルド不要・依存パッケージなしで動作します。

## 使い方

`index.html` をブラウザで直接開くだけで動きます。

```
start index.html
```

## 機能

- タスクの追加・編集（テキストをダブルクリック）・削除
- 完了/未完了の切り替え
- フィルタ表示（すべて / 未完了 / 完了済み）
- 完了済みタスクの一括削除
- localStorage による永続化（ブラウザを閉じてもデータが残る）
- ライト/ダークテーマ切り替え（右上の 🌓 ボタン）
